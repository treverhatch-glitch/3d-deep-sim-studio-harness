# Polish Checklist

Copy this into the game repo and check items off.

## Performance
- [ ] Stable frame rate on target hardware
- [ ] No major spikes during normal play
- [ ] Sim isolation check still passes

## Juice & feedback
- [ ] Important actions have clear visual feedback
- [ ] Audio cues exist for key events (in presentation layer)
- [ ] Failures and successes are readable

## Readability
- [ ] UI text is legible
- [ ] Core goals are understandable without external docs
- [ ] No critical information is hidden

## Audio
- [ ] SFX levels are balanced
- [ ] Music does not mask important cues
- [ ] Audio lives outside the pure sim

## Final
- [ ] At least one full playtest report exists
- [ ] No open P0 bugs
- [ ] Seed replay works for the last known failure
