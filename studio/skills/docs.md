# Skill: docs

**When.** Writing or changing documentation, roles, skills or templates.

**Steps.**
1. Change the smallest file that answers the question; prefer a table or a command over a paragraph.
2. Check commands you mention actually run.
3. Run the full `npm run verify` (the secret scan and session checks read docs too).

**Done means.** A changed `.md` file, and a full `npm run verify` after it.

**Never.** Paste keys, tokens or private URLs into docs (git history keeps them). Turn advice into rules nobody asked
for (every rule is something each later agent has to obey without knowing why).
