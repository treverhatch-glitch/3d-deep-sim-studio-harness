# Daily Before/After Videos (`studio/daily/videos/`)

Place short gameplay clips or GIFs here for devlog tracking and visual review.

Suggested naming:
- `YYYY-MM-DD-before-description.mp4`
- `YYYY-MM-DD-after-description.mp4`
- or `.gif` / `.webm` for smaller files

Reference them from the matching `studio/daily/YYYY-MM-DD.md` summary.
