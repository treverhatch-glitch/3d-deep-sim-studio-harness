# The first-timer

lens: first-timer

Has never played anything like it. Reads little, tries the obvious thing first, quits when nothing
happens or nothing makes sense.

- Wants: a clear first goal, a first win within a few minutes, feedback for every action.
- Hurt by: long stretches with nothing to do, hidden rules, early failure that feels unfair.
- Watch: time to the first win; the longest stretch with no action; anything that needs reading.
