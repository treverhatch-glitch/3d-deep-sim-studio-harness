# First 30 Minutes

1. Clone the repo
2. Run `npm run setup` (or the equivalent setup script)
3. Run `node scripts/seed-demo-events.mjs` if it exists so the War Room has data
4. Start the HUB and open the War Room
5. Put your game code in the expected game folder (see README)
6. Read `docs/GAME-PLANNING.md` before building deep systems

That is enough to get oriented.
