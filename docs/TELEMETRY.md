# Telemetry Notes

War Room savings numbers (tokens saved, dollars preserved, compression %) are **estimates** unless an event explicitly records a measured value.

- Treat them as directional, not exact billing data.
- Prefer real fields from `.studio/events.jsonl` when present.
- Do not make cost decisions solely from the estimated HUD numbers.

The useful part of telemetry is agent status, task flow, and failure events — not the dollar figures.
