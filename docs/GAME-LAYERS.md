# Game Layers

## Early game
- Core loop is clear and fun in the first 5–10 minutes
- Player understands the basic actions and goal
- Done when: a new player can complete the first meaningful cycle without help

## Mid game
- Systems start interacting
- Goals expand and choices appear
- Done when: multiple systems affect each other and the player has meaningful decisions

## End game
- Long-term goals, mastery, or win/lose conditions exist
- Done when: there is a clear late-game purpose and the player can reach it

Agents should define what “done” means for the current layer before moving to the next.
