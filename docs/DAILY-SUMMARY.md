# Daily Summary

End-of-day (or end-of-session) record of what happened, with optional before/after gameplay videos and a task checklist.

## Where It Lives

`studio/daily/YYYY-MM-DD.md`

Copy `studio/daily/TEMPLATE.md` and fill it in.

## What to Include

- Short bullets of what was done
- Checklist of tasks (checked or still open)
- Before/after gameplay videos or GIFs when visuals changed
- Key file or system changes
- Blockers and the single next focus
- Links to commits, playtest reports, or `studio/done/` summaries

## Videos

- Prefer short clips or GIFs showing the same moment before and after a change.
- Store them in the repo (e.g. `studio/daily/videos/`) or link to an external host.
- Name them clearly: `YYYY-MM-DD-before-turnaround.mp4`, `YYYY-MM-DD-after-turnaround.mp4`.

## Who Writes It

- Producer or the main agent at the end of a work block.
- Can be assembled from `studio/done/` summaries + the event log.

## Relation to Other Files

- `CURRENT_TASK.md` = live handoff (updated constantly)
- `studio/done/` = per-task summaries
- `studio/daily/` = daily rollup with visual before/after

Agents should create or update the daily file before ending a significant session.
