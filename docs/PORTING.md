# Late-Game Porting Bridges (`docs/PORTING.md`)

Because `src/sim/` and `cartridges/` are 100% pure TypeScript/JavaScript with zero DOM or Three.js imports (`node scripts/check-sim-isolation.mjs`), your simulation core can be packaged or ported to native desktop and console engines at any milestone without rewriting game rules.

---

## 1. Tauri v2 Desktop & Steam Packaging (Fastest Path — Keep Three.js)

1. Install the Tauri v2 CLI and FS plugin:
   ```bash
   npm install -D @tauri-apps/cli@latest
   npm install @tauri-apps/plugin-fs
   npx tauri init
   ```
2. Point `src-tauri/tauri.conf.json` `build.frontendDist` to `../dist` and `build.devUrl` to `http://localhost:5173`.
3. Persist deterministic JSON saves (`window.__sim.serialize()`) via `@tauri-apps/plugin-fs` and wire Steam achievements/cloud saves via the Rust `steamworks` crate.

---

## 2. Godot 4 Porting Bridge (`johnfn/ts2gd` + `Coding-Solo/godot-mcp`)

1. Run `node scripts/check-sim-isolation.mjs` to verify zero browser leaks in `src/sim/`.
2. Transpile pure TypeScript simulation modules to GDScript (`ts2gd`) or keep the simulation running in a lightweight sidecar while Godot 4 renders `MultiMeshInstance3D` scenes.
3. Connect `Coding-Solo/godot-mcp` so coding agents can inspect the Godot scene tree, read `public/assets/*.glb` meshes generated by `tools/blender/generate_glb.py`, and run deterministic seed replays.

---

## 3. Concrete Unity First-Steps Checklist (`nickna/SharpTS` / C# Bridge)

When porting a validated TypeScript 3D deep-sim into **Unity 6 / LTS**:

- [ ] **Step 1 — Verify Sim Purity & Seed Replay Baseline**:
  Run `node scripts/check-sim-isolation.mjs` and `node harness/replay.mjs --seed 42069 --tick 120` to record your reference state hash (`sha256`) and JSON snapshot at tick `120`.
- [ ] **Step 2 — Compile or Transpile `src/sim/` via `SharpTS`**:
  Use [`nickna/SharpTS`](https://github.com/nickna/SharpTS) (TypeScript-to-.NET IL/C# compiler) to compile `src/sim/` into a pure `.dll` assembly (or C# classes) and drop it into `Assets/Plugins/SimCore/`.
- [ ] **Step 3 — Wire Unity's `FixedUpdate()` to Deterministic `step(state, action)`**:
  Create a single `SimBridgeBehaviour : MonoBehaviour` that advances `SimCore.Step(state, queuedAction)` inside `FixedUpdate()` (never `Update()` with variable `Time.deltaTime`).
- [ ] **Step 4 — Verify Identical Seed + Tick Hash in Unity Test Runner**:
  Run seed `42069` for `120` ticks inside a Unity EditMode NUnit test and assert the serialized state matches the Node.js reference snapshot from Step 1.
- [ ] **Step 5 — Import `.glb` Props & Bind `Graphics.RenderMeshInstanced`**:
  Copy `public/assets/*.glb` (generated by `tools/blender/generate_glb.py`) into `Assets/Art/Models/` and map `state.entities` transforms to `Graphics.RenderMeshInstanced` batches.
