# Game Loops

Fill these in for the game. Keep them short.

## Core / Session loop
- Player does X → gets Y → decides Z → repeats

## Economy loop
- Sources of resources
- Sinks
- What creates interesting choices

## Progression loop
- How the player gets stronger or unlocks more
- What gates progress

## Meta loop
- What persists between sessions
- Why the player returns

Agents should complete these before building deep systems.
