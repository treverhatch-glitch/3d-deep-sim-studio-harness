# Game Planning

Start here when beginning a new game. Fill planning docs before writing deep systems.

1. Read `docs/GAME-LAYERS.md` — early / mid / end game
2. Fill `docs/GAME-LOOPS.md` templates for the core loops
3. Sketch a tech tree in `studio/templates/tech-tree.md`
4. Copy `studio/templates/vertical-slice.md` and define the first playable
5. Use the Reference Scout role to gather references (`studio/roles/reference-scout.md`)
6. Record approvals in `studio/references/APPROVALS.md`
7. Follow `docs/ART-PIPELINE.md` for turning approved references into assets
8. Keep audio and narrative out of the pure sim (`docs/AUDIO-AND-NARRATIVE.md`)
9. Use `studio/templates/polish-checklist.md` before calling a milestone polished

Do not jump straight into code. Plan the layers and loops first.
Check `docs/HEALTH.md` for the first-playable definition.
