# Game Planning

Start here when beginning a new game.

1. Read `docs/GAME-LAYERS.md` — early / mid / end game
2. Fill `docs/GAME-LOOPS.md` templates for the core loops
3. Sketch a tech tree in `studio/templates/tech-tree.md`
4. Use the Reference Scout role to gather references (`studio/roles/reference-scout.md`)
5. Record approvals in `studio/references/APPROVALS.md`

Do not jump straight into code. Plan the layers and loops first.
